# 红果榜单云端数据

GitHub Actions 按北京时间检查红果官网的综合、真人、AI 和漫剧热播榜。10:00–11:30 和 18:00–24:00 每半小时一次，其余检查点为 02:00、04:00、06:00、08:00、13:30、15:30、17:30。官网数据更新后替换当日快照，更新名次、热度与收藏等指标。3 天、7 天和 30 天趋势仍使用每个自然日的最新快照。首次上线前的历史批次来自此前已保存的公开榜单快照。

GitHub Pages 提供 `snapshot.json` 和 `series/<剧集编号>.json`。仓库和发布物只包含红果公开榜单数据。

`topics.json` 随同一批次发布。选题预测按四榜最佳名次加权，跨榜去重后将多题材剧的权重均分。早期缺档使用 `data/topic-archive.json` 中的公开上榜记录补齐。由题材相对份额、持续天数和最近单剧热度变化组合研判。

`topics.json` 的 `tagRadar` 提供 3 天、7 天、30 天的原始标签趋势、最多各 20 个升温与降温标签，以及去重后的关联剧。3 天档比较最近 3 天和此前 3 天的份额；7 天与 30 天档比较对应两端的 7 日均值。题材净热度只统计周期两端可比的剧集，多题材剧均分热度变化，并单列可比样本量与涨跌剧数。

`snapshot.json` 的各周期包含单剧爆点。爆点取最近 1–3 天有真实记录的涨幅，使用同周期上涨样本的第 90 百分位，且至少达到 1 天 100 万、2–3 天 200 万。题材净跌、缺少长周期基准、同题材作品较少均不影响单剧爆点识别。

题材详情提供收藏总增、两端收藏都可比的剧数、收藏上涨的剧数及涨幅最高的剧。收藏总增只加总增加量，多题材剧按所属题材均分；领涨剧展示该剧自己的完整收藏增量。

`ideas.json` 随每日流程生成选题评分对照库，覆盖已有公开四榜归档及相关剧集详情，包含剧名、公开标签、最佳榜位和近期热度或收藏变化。不含用户输入的选题。
