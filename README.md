# 红果榜单云端数据

GitHub Actions 在北京时间每天 11:07、14:07、18:07 检查红果官网的综合、真人、AI 和漫剧热播榜。官网数据更新后，保存每日快照并计算名次变化、日均热度增量、收藏增量和热度增长率。若当天已有快照，沿用已保存批次。首次上线前的历史批次来自此前已保存的公开榜单快照。

GitHub Pages 提供 `snapshot.json` 和 `series/<剧集编号>.json`。仓库和发布物只包含红果公开榜单数据。

`topics.json` 随同一批次发布。选题预测按四榜最佳名次加权，跨榜去重后将多题材剧的权重均分。早期缺档使用 `data/topic-archive.json` 中的公开上榜记录补齐。由题材相对份额、持续天数和最近单剧热度变化组合研判。

`topics.json` 的 `tagRadar` 提供 7 天、30 天的原始标签趋势、最多各 20 个升温与降温标签，以及去重后的关联剧。标签优先级以最近 3 天相较前 3 天的榜单份额变化为主，并考虑所选周期趋势和系列支持面。
